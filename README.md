# BehaviorTrackJS  
A lightweight, plug-and-play user behavior tracking component built with JavaScript, PHP (MySQLi), and HTML/CSS.  

This component records:
- Click events  
- Mouse movement  
- Scroll depth  
- Idle time  
- Time spent  
- Last interaction  
- Timestamped logs saved in MySQL  

Perfect for analytics dashboards, A/B testing tools, UX studies, or learning how tracking systems work.

---

## 🔧 Features
- Zero dependencies  
- Works on any HTML page  
- Tracks user events automatically  
- Async event logging using Fetch API  
- Fast, lightweight, and extensible  
- MySQL storage for event history  
- Can be integrated into any project
